# 快速开始

## 什么是 AI-OS-Application？

AI-OS-Application 是一个为 AI Agent 设计的能力生态系统。它将传统"应用"的概念解构为更细粒度的能力模块，让 AI Agent 能够：

- 🧩 **组合能力** - 像搭积木一样组合不同技能
- 📚 **继承经验** - 复用他人的调试经验和最佳实践
- 🔄 **运行工作流** - 执行预定义的自动化流程
- 🎯 **完成场景** - 实现完整的业务场景

## 核心概念

### 1. Skill（技能）
最小的能力单元，包含：
- 使用说明（SKILL.md）
- 执行脚本
- 提示词模板
- 经验记忆

### 2. Tool（工具）
可被技能调用的工具封装，如：
- API 客户端
- 自动化脚本
- 数据处理器

### 3. Workflow（工作流）
多个技能的编排，定义：
- 执行顺序
- 触发条件
- 状态管理
- 错误处理

### 4. Scenario（场景）
完整的业务场景，包含：
- 多个工作流
- 所需技能和工具
- 配置和记忆

## 使用方式

### 方式一：直接使用技能
```
1. 找到需要的技能目录
2. 阅读 SKILL.md
3. 配置依赖
4. 按说明使用
```

### 方式二：运行工作流
```
1. 找到工作流目录
2. 阅读 WORKFLOW.md
3. 配置 config 文件
4. 设置触发方式（手动/定时/事件）
5. 运行
```

### 方式三：部署完整场景
```
1. 找到场景目录
2. 阅读 SCENARIO.md
3. 安装所有依赖技能
4. 配置所有工作流
5. 启动场景
```
