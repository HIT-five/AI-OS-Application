# 今日头条健康养生内容发布结构化提示词

## 一、内容创作流程

### 1. 话题研究
- 使用 web_search 搜索最近相关健康/养生话题的权威研究文献
- 优先选择：NEJM、BMJ、Nature子刊、中国卫健委公告、中国营养学会白皮书、等权威期刊或者机构的研究
- 补充来源：三甲医院科普专栏、权威医学自媒体（丁香医生、腾讯医典）
- 提取核心发现和数据，标注研究出处（期刊名称、发布时间、样本量等）

### 2. 标题构建原则
- 不要直接使用原话题作为标题，聚焦用户核心痛点
- 采用提问式 / 警示式 / 数据式开头强化吸引力
- 加入权威感词汇：医生、研究、专家、临床研究、三甲医生、权威期刊
- 加入具体可验证数据提升可信度
- 结尾明确价值导向（解决方案 / 健康收益）

标题模板：
- [普适性痛点]？《XX 期刊》最新研究：[核心结论 + 量化数据]
- 风险提升 XX%！[特定人群] 需警惕，这类习惯正在透支健康
- 门诊中 80% 患者都踩坑！医生：[核心建议] 才是正确做法

### 3. 文章结构（故事化）

```
【吸引力标题，可用括号或emoji开头】

[故事引入段]
- 以真实医疗/生活场景开头（如：门诊中80%的高血压患者都会问、社区体检中6成中老年人存在、康复科接诊数据显示）
- 描述大众普遍存在的健康问题场景，避免个人化故事（如"隔壁王大爷"等模板化表述）
- 引出核心话题，强化问题的普适性

[权威背书段]
- 引用研究来源（如：《英国医学杂志》最新研究（要真实可信，不要胡编乱造））
- 给出关键数据和发现（样本量、随访时长、核心结论数值）
- 用通俗语言解释研究结论的健康意义

[核心内容段]（分点列举，不使用加粗符号）
用 emoji + 小标题的形式，如：
🔹 第一点：xxx
内容...

🔹 第二点：xxx
内容...

（列举3-7个要点）

[实操建议段]
💡 临床医生/营养科专家建议：
- 具体可操作的行为建议（附量化标准，如"每日摄入量不超过200g"）
- 结合人群特征给出差异化建议（如"中老年人群建议..."）

[故事收尾段]
- 总结核心健康价值，强化行为改变的必要性
- 呼应开头的普适性场景，提升用户共鸣

[互动引导]
提问引导评论，如：
你平时有没有注意过这个问题？评论区说说你的看法～
身边是不是好多人都有这习惯？快来聊聊～
这些小细节你都做到了吗？评论区交个作业😜
有没有踩过这些坑？说说你是怎么调整的～
你觉得这招有用吗？反正我身边试了的人都说管用～

【原创声明： 白大褂聊生活】

[话题标签]
#标签1 #标签2 #标签3 #标签4
```

### 4. 内容规范
- 字数：700-1000字
- 不使用 **加粗** 等特殊markdown符号
- 用 emoji 和换行来增强可读性
- 所有数据必须标注明确出处（权威期刊 / 医疗机构 / 临床统计）
- 语言风格：通俗化但避免过度口语化，兼顾专业感与接地气
- 替换 "隔壁王大爷 / 李阿姨" 等模板化个人故事，采用 "门诊数据 / 社区体检 / 临床观察" 等真实感场景

## 三、配图/封面提示词原则
- 与文章主题强相关的真实生活 / 医疗场景
- 温馨、自然的中式生活化场景（如家庭厨房、社区公园、门诊咨询场景）
- 包含文章核心元素（如提到的食物、运动方式、健康监测工具）
- 风格：写实摄影风格，暖色调，贴近普通家庭生活，避免过度摆拍感
- 人物呈现：多元化人群（不同年龄段），符合文章提及的目标人群特征

封面提示词模板：
"[核心场景：如社区门诊 / 家庭餐桌 / 公园散步]，[核心行为：如医生讲解 / 准备健康餐 / 做舒缓运动]，[关键元素：如当季蔬菜 / 血压计 / 瑜伽垫]，中式家庭风格，暖色调，写实摄影，自然光影，无过度修饰"

## 四、文章发布脚本说明

### publish_article_v2.py 参数说明
| 参数 | 说明 | 必填 |
|------|------|------|
| --title | 文章标题 | 是 |
| --file | 文章内容文件路径 | 是 |
| --cover | 封面图片路径（本地文件） | 否 |
| --cover-prompt | 用即梦AI生成封面的提示词 | 否 |

### 关键注意事项
1. **必须使用 xvfb-run 运行**：headless模式下预览弹窗无法弹出
2. **无封面时会自动选择"无封面"选项**：确保发布流程顺利
3. **封面支持两种方式**：
   - 本地图片：使用 `--cover /path/to/image.jpg`
   - AI生成：使用 `--cover-prompt "描述文字"`
