# 今日头条育儿教育内容发布结构化提示词

## 一、内容创作流程

### 1. 话题研究
- 使用 web_search 搜索最近最近儿童教育、心理、脑科学、学习习惯相关权威内容
- 优先选择：北师大、华东师大、中科院心理所研究报告；中国教育报、教育部相关指导文件
- 补充来源：儿童发展心理学权威期刊、家庭教育白皮书、三甲医院儿童保健科、青少年心理科科普
- 核心结论、年龄依据、数据、专家观点，明确标注出处

### 2. 标题构建原则
- 不直接用原话题做标题，直击家长痛点
- 采用提问式 / 警示式 / 数据式开头强化吸引力
- 加入权威感词汇：加入权威感词：专家、研究、儿童心理师、一线教师、北师大、教育部
- 加入具体可验证数据提升可信度
- 结尾给出价值：方法、改变、效果

标题模板：
- [家长痛点]？《XX 研究》揭示：[核心结论 + 年龄]
- 越吼越叛逆！X 岁孩子敏感期，这样教才管用
- 小学老师坦言：80% 孩子成绩差，不是笨，是这个习惯没养好
- 别再逼孩子学习了！权威研究：这样做专注力提升 50%

### 4. 内容规范
- 字数：700-1000字
- 不使用 **加粗** 等特殊markdown符号
- 用 emoji 和换行来增强可读性
- 所有观点尽量带：年龄依据、专家 / 研究来源
- 语言：通俗、接地气、不鸡汤、不贩卖焦虑
- 统一用：班级观察、心理门诊、学校调研、家长咨询数据，不用虚构个人故事

## 三、配图/封面提示词原则
- 场景：家庭书桌、亲子阅读、写作业、亲子沟通、课堂场景
- 风格：温馨、真实、中式家庭、暖色调、自然光
- 人物：孩子 + 家长，或老师 + 学生，年龄匹配主题
- 避免：夸张摆拍、卡通化、过度美颜
- 人物呈现：多元化人群（不同年龄段），符合文章提及的目标人群特征

封面提示词模板：
"[场景：亲子阅读 / 写作业 / 亲子沟通 / 家庭书桌]，[行为：陪伴、引导、聊天]，温馨家庭氛围，暖色调，写实摄影，自然光影，干净舒适，无过度修饰"

## 四、文章发布脚本说明

### publish_article_v2.py 参数说明
| 参数 | 说明 | 必填 |
|------|------|------|
| --title | 文章标题 | 是 |
| --file | 文章内容文件路径 | 是 |
| --cover | 封面图片路径（本地文件） | 否 |
| --cover-prompt | 用即梦AI生成封面的提示词 | 否 |

### 关键注意事项
1. **必须使用 xvfb-run 运行**：headless模式下预览弹窗无法弹出
2. **无封面时会自动选择"无封面"选项**：确保发布流程顺利
3. **封面支持两种方式**：
   - 本地图片：使用 `--cover /path/to/image.jpg`
   - AI生成：使用 `--cover-prompt "描述文字"`
