## 使用方式

```python
import json

with open('topics.json', 'r', encoding='utf-8') as f:
    data = json.load(f)

# 展平为列表
topics = []
for age_group, categories in data['育儿教育话题图谱'].items():
    for category, topic_list in categories.items():
        topics.extend(topic_list)

# 获取指定索引的主题
next_topic = topics[current_index % len(topics)]
```
