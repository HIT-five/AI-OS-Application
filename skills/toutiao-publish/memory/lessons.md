# 今日头条发布技能 - 经验记录

## 问题与解决

### 问题1：ChromeDriver版本不匹配
- **现象**：`version_main=144` 与系统Chrome 145不匹配，启动失败
- **原因**：undetected-chromedriver需要指定正确的Chrome版本
- **解决**：修改 `version_main` 参数匹配系统Chrome版本
- **日期**：2026-03-03

### 问题2："无封面"选择失败
- **现象**：Selenium原生click被其他元素拦截
- **原因**：页面元素覆盖导致点击位置偏移
- **解决**：改用 ActionChains + XPath 点击 label
- **日期**：2026-03-03

### 问题3：预览弹窗不弹出
- **现象**：点击"预览并发布"后没有弹窗
- **原因**：
  1. 未选择"投放广告赚收益"
  2. 标题超过30字限制
  3. headless模式下弹窗无法渲染
- **解决**：
  1. 添加选择广告收益的步骤
  2. 确保标题≤30字
  3. 使用xvfb-run运行
- **日期**：2026-02-28

### 问题4：Cookie失效
- **现象**：登录状态丢失，跳转到登录页
- **原因**：Cookie过期或被刷新
- **解决**：定期更新Cookie文件
- **日期**：持续

## 最佳实践

1. **标题控制**：始终检查标题字数，≤30字是硬限制
2. **封面选择**：单封面比无封面流量更好
3. **正文格式**：不用H1标题，全部普通段落`<p>`
4. **运行环境**：Linux下必须用xvfb-run
5. **超时设置**：发布脚本建议180秒超时
6. **图片生成**：即梦AI建议300秒超时

## 踩坑记录

- ❌ 错误做法：headless=True 直接运行
- ✅ 正确做法：xvfb-run -a python3 script.py

- ❌ 错误做法：标题32字"2岁宝宝沉迷电视，儿科医生：每天超过这个时间，危害远超你想象"
- ✅ 正确做法：标题28字"2岁宝宝沉迷电视？儿科医生：每天别超这个时长"

- ❌ 错误做法：在任意目录运行即梦AI脚本
- ✅ 正确做法：cd到技能目录再运行（需要读取config.json）
